# Автотесты и QA gates — отложено

Автоматические тесты (Playwright E2E, unit-тесты в Rust core, обязательный `axe` и perf thresholds в CI) **временно не поддерживаются** репозиторием.

## Что не запускается в CI по умолчанию

- E2E сценарии из [`test-plan-mvp.md`](test-plan-mvp.md)
- Rust `#[cfg(test)]` в `core` (удалены до восстановления)
- Регрессионные проверки из [`requirements-checklist.md`](requirements-checklist.md), завязанные на автотесты

## Когда вернуть

См. общий план продукта: фаза восстановления тестов после стабилизации ядра и UI.

## Ручная проверка

До появления автотестов — ключевые сценарии (установка, переключение профиля, конфликты) проверять вручную на пилотной игре.
